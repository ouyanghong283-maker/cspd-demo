# 合同字段来源映射清单

`contract-field-map.json` 是合同实体（`alp_contract`）来源字段的静态清单，逐项保留逻辑名、类型、来源分类、拟定本地对象与路径、编辑规则、CSPD口径、字典/关联线索、证据文件和源行号；主表单定位另链接到表单定位 CSV 的源行号。

## 来源与口径

- 全量字段及拟定去向：`doc/PRD/DEMO PRD/V7PRD/附件/01_标准CRM全量字段去向.csv`
- 主表单字段定位：`doc/PRD/DEMO PRD/V7PRD/附件/02_当前主表单字段定位.csv`
- 字段计数与处理说明：`doc/PRD/DEMO PRD/V7PRD/附件/README.md`

本次来源文件中 `alp_contract` 共 100 个字段名且没有重复逻辑名，与附件 README 的 100 条元数据字段数一致。原始分类归并如下：业务字段和业务状态归为 `business`；只读业务字段与派生/伴随字段归为 `readOnly`；系统字段与本地主键/来源标识归为 `technical`。原始分类仍在每条记录中保留。

`reviewFlags` 只标记来源明确写出的未决信息，例如规则待核验、当前表单必填运行时证据未取到、字典信息含未知项。标记旁保留来源原文，不自行决定合同状态映射、金额口径、字段公式、字典或 CSPD 必填。未决标记为空也只表示来源没有匹配到这些明确提示，不表示字段已在应用中实现或已独立验证。

拟定对象和路径转录自字段去向附件，不代表 Store 或页面已承载。专项测试逐项与两个来源 CSV 比对字段、去向、类别、来源行号、表单定位行号及未决标记，并检查 100 条唯一覆盖。
