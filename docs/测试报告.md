# CSPD前端DEMO测试报告

> 2026-10-12补充复核：下文为原分段测试记录，不代表全部需求已完成。同一对象全过程实测发现WBS收口、接收前校验、独立上手及数据一致性缺口，当前完整性结论见[全过程复核报告](功能完整性与全过程复核_2026-10-12.md)。

验收日期：2026-10-10。测试工具：官方 Chrome DevTools MCP 1.10.1，通过 MCP SDK 客户端实际启动 Chrome for Testing；使用真实页面、控件、文件上传和截图。

## 结果

- Angular 严格生产构建通过，无构建警告。初始资源约362KB，预估传输约96KB，各功能按路由懒加载。
- 9项业务规则测试通过，失败0。
- 19组浏览器页面与交互检查通过，失败0，记录的控制台错误0。
- 34个练习入口逐条点击通过，进入的路由、角色、详情标签及相关计划类型正确。非成员按设计隐藏内部详情。
- 客户主数据跨页面同步通过；10份PDF样例均HTTP 200且具有真实PDF文件头。
- 检查1440×1000桌面和390×844窄屏；主要页面无整页横向溢出，长表格在容器内滚动。
- 浏览器走查后已恢复初始样例。

## 页面范围

工作台、商机看板、线索列表、商机列表、客户联系人、项目列表、演示控制、销售详情、项目详情。销售详情7个标签；项目详情7个标签及7类计划。13种角色均实际切换。
