# 报价字段来源映射清单

`quote-field-map.json` 是报价单（`quote`）与报价明细（`quotedetail`）来源字段的静态清单。它按来源 CSV 逐字段保留逻辑名、字段类型、原始分类、拟定本地对象与路径、编辑规则、枚举/关联线索、CSPD 口径、证据文件及源行号；当前主表单定位另链接到表单定位 CSV 的行号。

## 来源与口径

- 全量字段及拟定去向：`doc/PRD/DEMO PRD/V7PRD/附件/01_标准CRM全量字段去向.csv`
- 主表单字段定位：`doc/PRD/DEMO PRD/V7PRD/附件/02_当前主表单字段定位.csv`
- 字段计数说明：`doc/PRD/DEMO PRD/V7PRD/附件/README.md`

来源附件说明 `quote` 有 197 个字段、`quotedetail` 有 158 个字段，合计 355 条。本清单保留来源的原始分类，并将其归并为三类便于检查：`业务字段` 与 `业务状态` → `business`；`只读业务字段` 与 `派生/伴随字段` → `readOnly`；`系统字段` 与 `本地主键/来源标识` → `technical`。

`reviewFlags` 只标记来源文字中明确存在的未决说明，例如未核验规则、未取得的运行时证据、未知选项或 CSPD 必填待核口径。空标记不表示字段已在应用中实现，也不表示其精度、公式或业务含义已独立核实。CSPD 必填值原样保留；CRM 元数据必填不会被转成 CSPD 必填结论。

清单里的目标对象和拟定路径是来源文件给出的映射决定，不是业务表单或 Store 的实现声明。缺值、来源未提供和待核规则均保持原文，不补猜测值。专项测试逐项对照两份来源 CSV，确保字段数量、唯一键、映射内容、分类及待核标记与来源一致。
