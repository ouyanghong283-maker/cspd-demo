# V4迭代与验收记录

开发依据：`doc/PRD/DEMO PRD/V4PRD`（V4.0，2026-10-13）。实现落在现有Angular Demo，不新建平行销售状态机。验收日期：2026-10-13。

## 本轮交付

- 销售资料统一模拟，文件名及说明可编辑；取消不创建记录。转商机保持实际销售与联系人，资料沿来源线索ID读取，重复转换返回原商机。
- 核心方案系列V1/V2递增，最新指针自动更新，最终标记独立、可查历史。方案业务责任人与操作人分开，项目查看原商机系列。
- 未发报价自动切换最新核心引用，保留需求来源及价格、配置、文字；待审及已审未发报价退回补充，关闭旧审核任务并保留审核历史。已发与锁定报价保留完整历史，新资料只生成销售核对提醒。
- 内部草稿允许资料不全；正式提交和模拟发出共用方案、质保、特殊服务复核及协议门禁。缺项可链接同一商机相应标签。
- 常规质保由销售确认，无运维任务；特殊服务可运维退回、销售补充重提、接受，意见按业务修订留存。关键内容修改立即失效确认和相关报价审核，普通备注保持确认。
- 服务协议支持待确认、适用、不购买；适用须模拟文件及条款摘要，再确认敲定。不购买须原因及销售确认，不免除质保。
- 项目费用只读筛选，按币种分别合计；SAP／CRM仅模拟标签。项目可加载独立快照，刷新保留回款事件。发票余额、账龄、逾期以2026-10-10为基准；未知日期和零分母明确显示。
- 财务模拟部分回款、收齐为累计额度，重复点击不累计、全额不回退；逾期余额与销售待办同步。
- 最终实际成本财务保存即生效，金额币种、范围、日期、提供人、模拟资料校验；修改须原因，新增修订，失败保留当前结果。费用、BOM和报价参考不自动合入成本。
- BOM由PM模拟留档，历史只读，项目隔离，不影响物料、计划或成本。
- V4 schema迁移保留旧ID和引用，不伪造方案或服务确认；损坏原始存储备份后显示初始数据。业务变更持久化成功才发布，失败保持旧状态。确认后整套恢复，取消无变化；清理旧IndexedDB文件范围已明确提示。
- 新写入口同时校验角色；非项目成员页面隐藏销售方案、服务及项目财务。普通角色仍沿用原Demo权限体系。

## 操作路径

1. 销售新建线索，模拟需求导入表，再转商机；补最低信息与等级，普通非投标进入方案报价。
2. 报价标签创建内部草稿；方案角色到方案标签模拟上传首版。
3. 销售到服务条件确认质保／SLA，并选择协议适用性。不购买填原因并确认；适用先模拟协议记录、选择文件、填写摘要，再确认条款。
4. 特殊服务由销售提交，运维在工作台进入当前修订复核；退回后销售改内容重提。
5. 报价补V2必填明细与商务字段并保存，先由财务在草稿阶段确认税费，再提交主管模拟审核。记录发出、客户接受、最终锁定后沿原流程洽谈、合同沟通、赢单、进入交付；已发报价不能补改税费。
6. PM在项目资料历史模拟BOM；财务在财务信息加载快照、模拟回款、先模拟成本资料再填最终成本。
7. 验证方案新版：未发版本换引用且重审，已发历史保持。最新与最终可分别指向不同版本。

控制页增加四个V4起点。原浏览器数据迁移不会自动追加新样例；要演示完整预置起点，使用控制页确认恢复全部示例。不要在需要保留操作的浏览器中重置。

- `scripts/browser-v4.mjs`在同一新建对象上运行线索→商机→报价→赢单→项目→BOM→财务和成本，另验证特殊服务、待办定位、历史隔离、窄屏、刷新及复位。部分原V2商务填写和项目桥接通过浏览器内调用现有store，新增界面操作通过实际按钮和弹窗；不将所有步骤宣称纯手工UI验收。

## 实现选择与边界

方案、服务、财务、成本使用V4对象集合；模拟附件扩展现有Attachment，`mode=simulated`、空URL，不另存File／Blob。旧附件ID稳定，查看仅元数据。服务变更的旧内容和确认快照记录在商机操作历史；运维复核意见留在服务修订历史。报价过期以`contentRevision`检测，避免旧表单覆盖新内容。

未发报价失效使用PRD建议的“退回补充”；原条件完整保存在审核日志，当前条件清空后重新审核。方案文件更新保持财务税费确认；交易条件变动仍用V2规则。财务新项目使用独立DEMO-SC，不复制同合同父项目快照或自动分摊成本。

所有身份、审批、SAP／CRM和文件都为单浏览器演示。未增加真实接口、原件读写、电子签署、预算、利润、成本审批或复杂WBS。权限保持原Demo角色模型，未构建真实账号认证。
