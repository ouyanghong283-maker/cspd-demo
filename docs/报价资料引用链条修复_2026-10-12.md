# 报价资料引用链条修复

日期：2026-10-12

## 问题与根因

商机附件已存在，保存报价草稿仍保留空的 sourceAttachmentIds。附件归属商机，提交审核却要求报价版本显式引用，保存动作未连接这两层关系。页面与校验各自读取附件，且未统一支持来源线索资料。

## 修复路径与结果

1. 统一可引用资料查询：当前商机及关联来源线索中的需求导入表、方案报价样例。
2. 创建、保存可编辑草稿时同步引用；保存保留合法历史引用并清理无效引用。
3. 页面展示、手工关联与提交审核使用同一资料范围，其他商机资料不得用于通过校验。
4. 增加“保存草稿并同步资料”入口，上传新资料后可明确执行同步；方案摘要为文字，不作为来源文件。
5. 保存时校验实际存储版本状态，防止旧草稿覆盖已提交版本。

## 验证

修复前：`npx tsx --test tests/quote-sources.test.ts` 失败，提示“保存草稿未引用已存在的需求资料”。

修复后：`npm test` 11项通过；`npm run build` 通过。新增回归检查覆盖保存到提交的引用一致性、跨商机误引用阻断、来源线索资料引用和已提交版本保护。

未执行浏览器端人工操作验收。现有浏览器数据中的可编辑草稿可以通过“保存草稿并同步资料”修复引用；已提交版本不会自动补改资料引用。
