在你的 Windows 电脑上
打开 CSPD 业务 demo

写给产品经理的动手指南。无需编程基础，每一步都有“做什么”和“怎样算成功”。第一次跟着做，之后只要双击「启动DEMO.bat」。

准备 下载 解压 装工具 双击启动 体验 下次使用 报错排查

开始前：你需要准备什么

你要把一套可点击的业务演示放到自己的电脑上。整套文件里已经带好了做好的页面，Node.js 是“启动用的工具”，装好一次就行。整个流程只有四步：下载 → 解压 → 装一次 Node.js → 双击「启动DEMO.bat」。你不需要打开命令窗口、不需要输入任何命令。

  • 一台 Windows 10 / 11 电脑，能安装软件；企业电脑若禁止安装，请找 IT 安装 Node.js。
  • Edge 或 Chrome 浏览器，以及能访问 GitHub 和 Node.js 官网的网络。
  • 建议预留 1 GB 空间。首次约需 10–20 分钟，这是操作估计，下载慢时会更久；下次使用只需双击启动。

本指南版本日期：2026-10-19。本 demo 不需要另装 Git、Python、数据库、VS Code 或全局 Angular，也不需要运行 npm 命令。

成功的标志：双击「启动DEMO.bat」后，浏览器自动打开本机演示页，你能选择角色、进入练习并保存一次操作。这是业务演示，审批、合同、生产和账务部分使用模拟结果。

1. 从 GitHub 下载整套文件

下载仓库：ouyanghong283-maker/cspd-demo。点击下方入口下载完整代码和本指南。

打开 GitHub 仓库 · 直接下载完整 ZIP

  1. 在浏览器打开仓库首页。公开仓库一般无需登录；私有仓库需要先登录 GitHub，且账号已被邀请。
  2. 在文件列表上方点击绿色的 Code 按钮。
  3. 在弹出的菜单里点击 Download ZIP，等待下载完成。不要逐个点文件下载。

操作依据：GitHub 官方下载说明。

如果拿到的是本指南同目录中的 CSPD-demo-分享包.zip，也可以直接使用它，从第 2 步开始。

2. 解压，并找到“真正的项目文件夹”

  1. 找到下载的 ZIP。右键点击它，选择 全部解压缩。
  2. 选择你有写入权限、路径较短的位置，例如 C:\Demo；若公司电脑不能写 C 盘根目录，使用个人“文档”文件夹也可以。
  3. 打开解压后的文件夹。继续找，直到看见 启动DEMO.bat 和 package.json 并排出现在同一层。如果最外层还有 my demo，就继续进入它。
看到 启动DEMO.bat 就说明你找对地方了，后面只要双击它。不要在 ZIP 预览窗口里双击，也不要双击 src/index.html：那只是材料的一部分，直接打开看不到完整 demo。

3. 安装 Node.js：让电脑有能力启动 demo（只装一次）

  1. 打开 Node.js 官方下载页。选择 24 LTS，版本至少为 24.15.0。LTS 可以理解成“适合稳定使用的版本”。核对时官网提供 24.21.0 LTS。
  2. 系统选择 Windows；普通 Intel / AMD 电脑选择 x64，ARM 电脑选择 ARM64。拿不准可在“设置 → 系统 → 系统信息 → 系统类型”查看。
  3. 下载 Windows Installer (.msi)。双击安装文件，按 Next → 接受许可 → Next → Install → Finish。保留默认安装项，特别是 npm 和 Add to PATH。
  4. 如果出现“自动安装额外工具”的选项，这个 demo 不需要勾选；无需另装 Python 或编译工具。
  5. 安装完成后直接回到项目文件夹双击「启动DEMO.bat」即可。安装时出现 Windows 授权提示，按公司电脑的管理要求处理。

装好 Node.js 之后，不再需要任何命令行操作：不需要打开命令窗口，也不需要输入 npm 命令，双击启动文件就能用。已有 Node.js？项目也支持 22.22.3 及以上的 22 系列，或 26.0.0 及以上版本；推荐使用 24 LTS。20 系列不适用。

4. 双击启动，浏览器自动打开 demo

  1. 回到第 2 步找到的项目文件夹（能看到 启动DEMO.bat 的那一层）。
  2. 双击「启动DEMO.bat」。会弹出一个黑色窗口，稍等几秒，窗口里会显示“ CSPD demo 已启动”。
  3. 浏览器会自动打开 demo 页面，地址通常是 http://127.0.0.1:4200。如果 4200 端口被占用，会自动换用 4201 等，以黑色窗口里显示的地址为准。
黑色窗口保持打开。它负责让页面持续运行；关掉它就像关掉样板间的电源，demo 页面会立即打不开。启动后窗口停在那里不动是正常的。

如果浏览器没有自动打开，把窗口里显示的那行地址（例如 http://127.0.0.1:4200）复制下来，粘贴到 Edge / Chrome 地址栏回车。也可以直接点：

启动成功后，点这里打开 demo

第一次双击时，如果窗口提示“尚未安装 Node.js”并自动打开了 Node.js 官网，说明第 3 步还没做：按页面提示下载 LTS 版本一路下一步安装，装完重新双击「启动DEMO.bat」即可。

127.0.0.1 表示“你这台电脑”。把这个网址发给同事，同事打不开你的 demo；同事要在自己的电脑按本指南启动。Mac 用户双击 启动DEMO.command，首次可能需要在“系统设置 → 隐私与安全性”里允许打开。

5. 先完成一次短练习，再演示完整流程

  1. 打开左侧 演示控制与指南。
  2. 在右上角或指南页面选择你的 业务角色。例如先选销售。角色是演示里的工作身份，不需要注册账号。
  3. 找一个对应角色的任务，点击 去练习。
  4. 按照页面上的缺项提示填写；遇到表单可以使用 填入演示内容。需要附件时优先用演示附件，也可上传自己的 PDF、Excel 或 Word。
  5. 点击该步骤的保存或完成按钮。刷新页面后，检查刚才的操作是否保留。

开会时怎样串起主线？

销售登记线索 补需求附件 → 转商机 完善商机 → 保存阶段沟通 记录赢单 → 进入交付演示 切换 PM → 接收与启动交底 维护计划 SAT 与客户验收分别完成 接收方确认移交

每一步按页面提示切换角色。按钮不能点时，先看缺什么资料、当前角色是否合适。重点投标可以看 DEMO-O002；交底缺件看 DEMO-P002；验收看 DEMO-P006；待接收看 DEMO-P007。

哪些行为会保存，哪些不会共享？

  • 修改保存在当前浏览器；刷新、切角色和切案例通常保留修改。换浏览器、电脑、浏览器用户或地址不会同步这些记录。
  • 固定使用黑色窗口里显示的那个地址（通常是 http://127.0.0.1:4200）。改用 localhost 或其他端口，会进入另一份浏览器存储，可能看起来像数据没了。
  • “重置演示数据”需要确认，并会清空本轮记录和上传文件；清理浏览器站点数据也会丢失本机记录。
  • 指南页可以导出业务记录、通知和历史；上传文件内容仅保留在当前浏览器，导出记录不能当成完整附件备份。
这是用于讨论业务流程的 demo。部分功能仍有待完善，不要将演示中的模拟审批结果当成真实业务审批。详细范围见项目 README 和 docs/功能完整性与全过程复核_2026-10-12.md。

6. 结束、下次使用与更新

今天结束

直接关闭那个黑色窗口即可，demo 随之停止；浏览器页签可以一并关掉。也可以在窗口里按 Ctrl + C，若询问 Terminate batch job (Y/N)?，输入 Y 并回车。

下次使用

打开同一个项目文件夹，双击「启动DEMO.bat」，浏览器会自动打开 demo。Node.js 不用重装，也不需要任何其他准备工作。

分享者说有新版本时

先关闭旧版本的黑色窗口，再从仓库重新下载 ZIP，解压到一个新文件夹，双击新文件夹里的「启动DEMO.bat」即可，不需要再装 Node.js。保留旧文件夹可方便退回旧版。继续使用相同地址可能沿用之前的浏览器记录；需要全新演示时，在确认不再需要旧数据后点击“重置演示数据”。

想了解仓库里的文件：src 是页面与业务逻辑，dist 是已经构建好、启动时直接使用的页面，public 是字体与样例附件，启动DEMO.bat / 启动DEMO.command 是双击入口，serve-demo.js 是它们调用的启动脚本，package.json 是项目说明与清单，docs 是需求和复核说明。体验 demo 时无需修改这些文件。

卡住时：按你看到的提示处理

双击「启动DEMO.bat」没反应，或窗口一闪而过

先确认你是在解压后的文件夹里双击，而不是在 ZIP 预览窗口里。仍不行时查看报错：点击文件资源管理器上方的地址栏，输入 cmd 回车，在打开的窗口里输入下面的命令并回车：

node serve-demo.js

把窗口里显示的报错截图，发给交付 demo 的同事，说明“双击启动没反应”。

窗口提示“尚未安装 Node.js”，并打开了官网

这是第 3 步还没完成。在打开的官网页面下载 LTS 版本的 Windows Installer (.msi)，一路下一步安装，装完后重新双击「启动DEMO.bat」。企业电脑不能装软件时请 IT 协助。

窗口显示已启动，但浏览器没有自动打开

手动复制窗口里显示的那行地址（例如 http://127.0.0.1:4200），粘贴到 Edge / Chrome 地址栏回车。黑色窗口要保持打开。

窗口提示“端口被占用”

新版会自动换用下一个端口（4201、4202……）并继续启动，一般不需要处理，以窗口里最终显示的地址为准。多半是上一次的黑窗口还没关；找到并关闭它，再重新双击也可以。

Windows 弹出“防火墙/网络访问”提示

这是 Windows 在确认是否允许 Node.js 提供本机服务。点击 允许访问；demo 只在你自己的电脑上运行，不会向外部发送数据。

页面能打开，但显示的是旧内容 / 和分享者说的不一样

浏览器可能缓存了旧版本。在 demo 页面上按 Ctrl + F5 强制刷新。若仍是旧内容，确认你双击的是新解压文件夹里的「启动DEMO.bat」，旧文件夹的黑色窗口已关闭。

需要别人帮你排查时，提供：卡在哪一步、黑色窗口里最后一段文字的截图、你是否已经装好 Node.js、你是否能在文件夹里看到 启动DEMO.bat。这些比只说“打不开”更容易定位问题。
